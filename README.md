# YouTube Live Visibility — інформаційний сайт

Публічні сторінки особистого застосунку:

- `index.html` — головна сторінка;
- `privacy.html` — політика конфіденційності.

Репозиторій містить лише статичний сайт. Автоматизація YouTube та OAuth Secrets залишаються в окремому приватному репозиторії.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Після успішного розгортання:

- https://leerina19918.github.io/youtube-stream-visibility-site/
- https://leerina19918.github.io/youtube-stream-visibility-site/privacy.html

Ці адреси працюватимуть після активації й завершення розгортання GitHub Pages.
