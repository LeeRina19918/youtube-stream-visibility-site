Особиста автоматизація YouTube Live

YouTube Live Visibility

Застосунок допомагає власниці YouTube-каналу автоматично відкривати заплановану приватну трансляцію в день її проведення.

Як це працює

Щодня о 10:00 за часовим поясом Europe/Warsaw GitHub Actions отримує майбутні трансляції через YouTube Data API v3. Якщо на поточну локальну дату запланована рівно одна приватна трансляція, її видимість змінюється на публічну.

Трансляції інших дат залишаються без змін. Якщо приватних трансляцій на сьогодні більше однієї або список результатів неповний, застосунок нічого не змінює й повідомляє про це у workflow.

Доступ до каналу

Власниця каналу надає доступ через Google OAuth. Застосунок використовує цей дозвіл для читання запланованих трансляцій і зміни їхньої видимості. OAuth credentials і refresh token зберігаються тільки у GitHub Actions Secrets.

Цей сайт є інформаційною сторінкою. Тут немає входу, форм збору даних або кнопки публікації трансляції; автоматизація виконується в GitHub Actions.
