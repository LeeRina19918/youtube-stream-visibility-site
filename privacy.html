Політика конфіденційності

Застосунок: YouTube Live Visibility. Останнє оновлення: 13 жовтня 2026 року.

Призначення

Це особиста автоматизація для YouTube-каналу, власниця якого добровільно надала доступ через Google OAuth. Вона змінює видимість однієї приватної трансляції, запланованої на поточну дату за Europe/Warsaw, на публічну.

Дані, які обробляються

Застосунок отримує від YouTube Data API v3 ідентифікатори, метадані запланованих трансляцій, час початку та статуси, зокрема видимість і налаштування аудиторії. Для авторизації використовуються OAuth client ID, client secret, refresh token і короткочасний access token.

Як використовуються дані

Дані використовуються лише для вибору трансляції на сьогодні та зміни її видимості. Застосунок не використовує їх для реклами, профілювання чи навчання моделей і не продає їх. Доступ до інших Google-даних не використовується.

Зберігання та доступ

OAuth credentials і refresh token зберігаються тільки у GitHub Actions Secrets приватного репозиторію. Access token і відповіді YouTube API обробляються в пам’яті під час запуску; застосунок не зберігає їх у базі даних або артефактах.

GitHub зберігає журнали й історію запусків відповідно до налаштувань репозиторію. Скрипт записує підсумковий результат або повідомлення про помилку, не друкує OAuth credentials чи відповіді API та маскує access token. Доступ до Secrets під час виконання має код workflow; тому редагування репозиторію слід дозволяти лише довіреним особам.

Сторонні сервіси

Google обробляє OAuth-авторизацію та запити YouTube API. GitHub надає Secrets, виконує workflow та розміщує цей сайт через GitHub Pages. Дані можуть оброблятися цими сервісами відповідно до їхніх політик: Google Privacy Policy та GitHub Privacy Statement.

Відкликання доступу та видалення

Власниця каналу може відкликати дозвіл у налаштуваннях підключень Google-акаунта. Щоб припинити автоматизацію, також вимкніть workflow у GitHub Actions і видаліть три OAuth Secrets у налаштуваннях репозиторію. Журнали запусків можна видалити в GitHub Actions. Відкликання доступу не повертає вже опубліковану трансляцію у приватний стан; її видимість можна змінити в YouTube Studio.

Відвідувачі сайту

Ці статичні сторінки не містять форм, аналітики, рекламних трекерів або власних cookies. GitHub Pages може обробляти технічні відомості, зокрема IP-адресу відвідувача, для роботи й захисту хостингу.

Зв’язок

Питання щодо цього особистого проєкту можна адресувати власниці через доступні способи зв’язку в її GitHub-профілі. Не надсилайте токени або інші облікові дані у зверненнях.
